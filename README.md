# iMac Fan Desk 0.5

Утиліта керування охолодженням для iMac18,3 під Windows із автозапуском у трей, індикатором температури та редагованою 4-точковою кривою обертів.

## Що нового у версії 0.5

- **Редагована 4-точкова крива температур:** за замовчуванням `55°C → 1200 RPM`, `80°C → 2700 RPM`, `85°C → 3200 RPM`, `90°C → 3600 RPM` з плавною лінійною інтерполяцією між точками.
- **Явний дозвіл на оберти вище `F0Mx` (до 3600 RPM):** прапорець у вікні дозволяє задавати цільові оберти `F0Tg` у діапазоні до `3600 RPM` (`F0AH`), оминаючи акустичне обмеження `F0Mx = 2700 RPM` без модифікації `F0Mx`, `F0Mn` чи ШІМ (`FPDc`), із перевіркою зворотного зчитування `F0Tg`.
- **Збереження попередніх версій:** версії `v0.1` (`iMacFanDesk-v1.backup.exe`), `v0.2` (`iMacFanDesk-v02.exe`), `v0.4` (`iMacFanDesk-v04.exe`) та нова `v0.5` (`iMacFanDesk-v05.exe`) збережені поруч у проєкті.

## Використання

- Програма: `%LOCALAPPDATA%\Programs\iMacFanDesk\iMacFanDesk.exe` (попередня версія збережена там же як `iMacFanDesk-v04.backup.exe`).
- Після входу у Windows запускається через 15 секунд з правами адміністратора у трей, без повторного UAC.
- Значок трея показує округлену температуру обраного датчика. Лівий клік відкриває вікно, правий — меню.
- Хрестик і згортання залишають керування активним у треї.
- «Вийти → системне Auto» в меню трея завершує програму й повертає керування прошивці.
- Повторний запуск exe відкриває вже запущену програму.

## Режими та датчики

- **«За кривою»** — регулює оберти за 4 точками, налаштування зберігаються у `%LOCALAPPDATA%\iMacFanDesk\curve.txt`.
- **«МАКСИМУМ»** — тримає максимальні оберти (до 3600 RPM при ввімкненому розширеному ліміті або `F0Mx` при вимкненому) незалежно від температури.
- **Типовий датчик — «Найгарячіший із CPU / GPU» (`HOT`)**: на кожному циклі обирається максимум `TCXc` і `TG0D`, щоб гарячий GPU під час ігор не ігнорувався.

## Файли

- Налаштування кривої: `%LOCALAPPDATA%\iMacFanDesk\curve.txt`.
- Вибір датчика: `%LOCALAPPDATA%\iMacFanDesk\sensor.txt`.
- Режим: `%LOCALAPPDATA%\iMacFanDesk\mode.txt`.
- Журнали: `%LOCALAPPDATA%\iMacFanDesk\logs`; помилки: `errors.log`.
