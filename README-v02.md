# iMac Fan Desk 0.2

Мінімальна утиліта для iMac18,3 з одним вентилятором.

## Використання

- Програма: `%LOCALAPPDATA%\Programs\iMacFanDesk\iMacFanDesk.exe`.
- Після входу у Windows запускається через 15 секунд з правами адміністратора у трей, без повторного UAC.
- Значок трея показує округлену температуру обраного датчика. Лівий клік відкриває вікно, правий — меню.
- Хрестик і згортання залишають керування активним у треї.
- «Вийти → системне Auto» в меню трея завершує програму й повертає керування прошивці.
- Повторний запуск exe відкриває вже запущену програму.
- У списку вибери датчик. Вибір одразу застосовується і зберігається між запусками.

## Один режим

До 55°C — мінімальні оберти SMC (на цьому iMac 1200 RPM). Між 55 і 80°C ціль зростає лінійно. Від 80°C — максимум SMC (2700 RPM). Нижче 55°C вентилятор не вимикається.

Типовий датчик — CPU TCXc. Можна обрати доступний датчик GPU, пам'яті або інший. Обраний датчик керує кривою і температурою у треї. При втраті його даних програма задає Max, значок показує «!». Це запит контролеру, не гарантія фізичного виконання.

Графік за останні 6 хвилин: фактичні RPM — синій, ціль SMC — жовтий пунктир, температура — червоний із правою шкалою. Окремо показано криву 55→80°C. Дані беруться з SMC; це не незалежне вимірювання потоку повітря.

## Файли

- Вибір датчика: `%LOCALAPPDATA%\iMacFanDesk\sensor.txt`.
- Журнали: `%LOCALAPPDATA%\iMacFanDesk\logs`; помилки: `errors.log`.
- Завдання автозапуску: `iMacFanDesk`, нормальний пріоритет, без обмеження часу роботи.
- Старе завдання `RPMac` вимкнене, не видалене. Його XML збережений у резервній папці встановлення.
- Програма зупиняє RPMac, якщо той запущений паралельно.
- Примусове завершення процесу не повертає Auto. Користуйся виходом через меню трея.
